# AutoCash - Autonomous Cash Application Agent

Live demo workspace (synthetic data). AutoCash matches incoming payments to
open invoices autonomously: AI proposes, deterministic solvers dispose.
MILP matching under a cash conservation equation, deduction intelligence,
cash-in forecasting, collections prioritisation, and a grounded copilot -
behind multi-tenant RBAC APIs. Seed the demo workspace from the dashboard
and run a reconciliation batch.

Full product README: see README_PRODUCT.md in this repo.
